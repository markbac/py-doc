# py-doc

py-doc turns Markdown technical documentation into Word documents, PowerPoint decks, PDF, HTML and web sites like this one. It checks the writing, draws diagrams, documents C4 architecture from Structurizr models, and imports Word and PowerPoint files.

This site is built by py-doc from its own sources, with `py-doc site build`.

- **[User guide](user-guide/00-introduction.md)**: install py-doc, start a project, write, build, check and publish.
- **[Requirements](requirements/00-introduction.md)**: what py-doc must do and how well, and the status of each requirement.
- **[Architecture](architecture/00-introduction.md)**: how py-doc is built, with C4 views of its own design, and the decisions behind it.

The source is on [GitHub](https://github.com/markbac/py-doc).
